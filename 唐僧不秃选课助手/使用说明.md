# 选课助手 · 使用说明

一个运行在你自己电脑上的「本地网页版」正方教务系统选课辅助工具。
程序只在本机运行（默认地址 `http://127.0.0.1:8787`），所有操作都由你本机的浏览器发起，账号密码只保存在你自己的电脑上。

> 请仅用于你本人有权操作的账号，并遵守学校相关规定。

---

## 一、运行环境

- **操作系统**：Windows / macOS / Linux 均可。
- **Node.js**：需要 18 或更高版本（推荐 LTS）。
  下载地址：<https://nodejs.org/> ，一路「下一步」安装即可。
- 本项目**零第三方依赖**，不需要联网安装 npm 包。

### 想完全免安装？(可选)
把便携版 Node 解压后，让 `node.exe` 位于本包根目录的 `node\` 文件夹下：

```
本整合包\
├─ node\
│  └─ node.exe      ← 放入便携版 Node
├─ 启动.bat
└─ ...
```

这样即使电脑没装 Node，双击 `启动.bat` 也能直接运行。

---

## 二、快速开始（Windows）

1. 把整个文件夹解压到任意位置（路径尽量不要有特殊符号）。
2. 双击 **`启动.bat`**。
3. 稍等片刻，会**自动打开浏览器**并显示控制台地址，形如：
   `http://127.0.0.1:8787/?token=xxxxxxxx`
   （若没自动打开，请手动复制窗口里打印的那行地址到浏览器）
4. 在控制台左侧进入 **【设置】**，填写你的 **学号 / 密码**，保存。
5. 进入 **【课程】** 页，搜索你要选的课 → 点击 **「加入监控」**。
6. 页面会跳到 **【任务】** 页并自动填好表单，核对后点击 **「创建任务」**。
7. 在任务行点击 **「开始」**，工具即开始按间隔轮询；一旦有名额会自动提交。
8. 使用结束后，**关闭那个黑色窗口**即可停止程序。

> macOS / Linux：在终端执行 `bash start.sh` 即可（首次可先 `chmod +x start.sh`）。

## 三、界面功能

| 页面 | 作用 |
| --- | --- |
| **总览** | 查看引擎状态、限流情况，启动/停止引擎、查看日志 |
| **课程** | 按关键词搜索课程与教学班，查看余量；可「加入监控」或「立即选课」 |
| **任务** | 创建/开始/暂停/重置任务，查看每轮轮询结果 |
| **设置** | 填写账号密码、学期、引擎参数、通知渠道等 |
| **抓包** | 当学校教务接口变动、工具失效时，用来重新校准接口 |

### 任务说明
- **开始**：持续监控并自动抢课（推荐）。
- **执行一次**：只跑一轮（调试用），跑完任务会停在「空闲」。
- **暂停 / 重置**：暂停轮询 / 清空统计重新开始。
- **模式**：
  - `auto` 自动抢课；
  - `watch` 仅监控，有名额时通知但不提交。

## 四、首次使用建议

1. 先到 **【设置】** 点一次会话检测，确认能正常登录。
2. 确认 **【设置】** 里的**学期**（学年/学期）是当前学期，否则搜不到课。
3. 可先用 **「执行一次」** 观察是否能正确匹配到课程、读到余量。

## 五、常见问题

**Q1：双击 `启动.bat` 一闪而过 / 提示找不到 Node**
说明没装 Node.js。请到 <https://nodejs.org/> 安装 LTS 版，或按上文放置便携版 `node\`。

**Q2：浏览器提示 401 未授权**
必须使用程序启动时打印的、**带 `token=` 的完整地址**访问，不能只输 `127.0.0.1:8787`。
每次重启程序 token 都会变化。

**Q3：提示「未匹配到目标课程」**
- 关键词为空时会全量搜索、较慢；建议在任务里填「查询关键词」，或直接用「加入监控」自动填入课程名。
- 确认学期是否正确。

**Q4：端口 8787 被占用**
到 **【设置】** 修改 `server.port`，或关闭占用该端口的程序后重启。

**Q5：提示需要验证码 / 登录被阻断**
部分账号需验证码登录。请在浏览器里手动登录教务系统，然后：
- 方案 A：在 **【设置】** 用「手动 Cookie」方式，填入 `JSESSIONID`、`route`（可从浏览器开发者工具 → 应用 → Cookie 中复制）；
- 方案 B：完成一次网页登录后，重新在工具里登录。

**Q6：换电脑 / 换账号**
本整合包已清空所有账号数据，**直接在新电脑上启动、在【设置】里填新账号即可**。
切勿直接拷贝别人电脑上的 `data\` 文件夹（里面的 `machine.key` 与本机绑定，拷过去反而不安全、也可能解不开）。

**Q7：接口失效、一直报错**
说明学校教务系统接口有调整，需要在 **【抓包】** 页按提示重新校准（导入一次真实请求的抓包内容）。

## 六、目录结构

```
选课助手/
├─ 启动.bat             Windows 启动脚本
├─ start.sh             macOS / Linux 启动脚本
├─ 使用说明.md           本文件
├─ package.json
├─ config/              配置（已内置本校已校准的接口定义）
│  ├─ config.json       主配置（账号、学期、引擎参数…）
│  ├─ actions.json      教务接口定义（已校准，请勿随意改动）
│  └─ result-rules.json 选课结果判定规则
├─ src/                 程序源码
├─ public/              网页控制台前端
├─ tools/               附带小工具（自检等）
└─ data/                运行时自动生成：Cookie、加密账号、任务、日志
                        （此目录含隐私，请勿外传）
```

---

## 七、安全与隐私

- 账号密码可用 **【设置】** 保存，会以 **AES-256-GCM 加密**存到 `data\secrets.json`，
  密钥为本机生成的 `data\machine.key`，**与换机无关**。
- 若你直接在 `config\config.json` 里写了密码，则是**明文**存储，安全性较低，建议改用【设置】页保存。
- 控制台仅监听 `127.0.0.1`，**仅本机可访问**，并带随机 token 鉴权。
- 不要把包含 `data\` 的文件夹发给他人。

---

## 八、停止程序

- 直接**关闭启动脚本的黑色窗口**；
- 或在窗口内按 `Ctrl + C`。

任务状态会保存在 `data\state.json`，下次启动可继续。
